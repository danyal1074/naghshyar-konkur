# نقش‌یار — فرانت‌اند سامانه‌ی کنکور هنر

React + Vite، راست‌چین و موبایل‌محور. سه نقش: **دانش‌آموز، مشاور، مدیر**.

## اجرا

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # خروجی در dist/ (استاتیک؛ روی هر هاستی کار می‌کند)
```

## حالت نمایشی (پیش‌فرض)

`USE_MOCK = true` در `src/config.js`: همه‌چیز با داده‌ی نمونه کار می‌کند و در مرورگر ذخیره می‌شود. برای ارائه کافی است `dist/` را روی هر هاست استاتیک (Netlify، Vercel، GitHub Pages…) بگذاری.

- ورود سریع: در صفحه‌ی ورود یا اول سایت روی نقش دلخواه بزن.
- ورود با شماره: `09124444441` (دانش‌آموز)، `09121111111` (مشاور)، `09120000000` (مدیر)؛ کد همیشه `12345`.
- منوی کاربر (بالا) → «ورود به‌عنوان …» برای دیدن سامانه از نگاه نقش دیگر و «بازنشانی داده‌های نمایشی».

## اتصال بک‌اند

1. `USE_MOCK = false` در `src/config.js`
2. endpointها را طبق **`API.md`** بساز.

هیچ صفحه‌ای مستقیم `fetch` نمی‌زند؛ همه از `src/api/index.js` می‌خوانند. `src/api/mock.js` و `src/api/http.js` توابع هم‌نام و هم‌شکل دارند.

## ساختار

```
src/
  config.js          تنظیمات (نام، تاریخ کنکور، نمره‌ی منفی، حالت mock)
  api/               mock.js · http.js · seed.js (سرفصل، سؤال، قالب برنامه)
  ui.jsx             دکمه، مودال، فرم، نمودار، آیکن
  components.jsx     اجزای مشترک (کار، پیشرفت، نتیجه، کار عملی)
  Shell.jsx          منوی کناری (دسکتاپ) و نوار پایین (موبایل)
  pages/             student1-3 · counselor1-2 · admin · Landing · Login
```

## امکانات

**دانش‌آموز:** صفحه‌ی «امروز» · برنامه‌ی هفتگی · آزمون با زمان‌سنج و نمره‌ی منفی · مرور پاسخ‌ها · پیشرفت و مبحث‌های ضعیف · زمان‌سنج مطالعه · ارسال کار عملی · دستیار درسی · اعلان‌ها

**مشاور:** فهرست دانش‌آموزان با وضعیت · برنامه‌ساز هفتگی (قالب آماده، کپی هفته، مرور برای مبحث ضعیف) · آزمون‌ساز سه‌مرحله‌ای (بانک سؤال + پیش‌نویس هوش مصنوعی) · نتایج و سخت‌ترین سؤال‌ها · بانک سؤال · بازبینی کار عملی

**مدیر:** مشاورها و اشتراک‌ها · پلن‌ها · آمار

## نکات

- نام «نقش‌یار» و قیمت پلن‌ها نمونه است.
- سرفصل‌ها و سؤال‌های نمونه برای نمایش‌اند؛ با محتوای واقعی جایگزین کن (به کپی‌رایت کتاب‌ها توجه کن).
- دکمه‌ی «پیشنهاد سؤال با هوش مصنوعی» و دستیار درسی در حالت نمایشی پاسخ‌های از پیش‌نوشته‌شده می‌دهند؛ در بک‌اند به مدل زبانی وصل می‌شوند (`/ai/questions`، `/ai/chat`).
